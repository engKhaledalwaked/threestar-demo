# استوديو تري ستار للتصوير — Three Star Studio (Demo)

نسخة عرض (واجهة أمامية) لموقع **استوديو تري ستار** في حي اليرموك بالرياض. Vue 3 + Vite، عربي/إنجليزي.

## التشغيل
```bash
npm install
npm run dev
```
الرفع على Vercel: ارفعه على GitHub ثم Import في Vercel (Build: `npm run build`، Output: `dist`).

## الأصول (`public/img/`)
كلها من صفحة الاستوديو على خرائط Google:
| الملف | المصدر |
|---|---|
| `brand-wall.jpg` | صورة جدار الهوية الجديدة (ثلاث نجوم + THREE STAR STUDIO) |
| `portfolio-*.jpg` | الصور المؤطّرة الخمسة من نفس الجدار (عائلة، عائلة واقفة، إخوة، أم وطفل، مولود) |
| `storefront-day.jpg` / `storefront-night.jpg` | واجهة المحل نهاراً وليلاً |
| `interior.jpg` | جزء من الاستقبال (قُصّ ليستبعد الصور الرسمية المعلّقة) |

الشعار (`StarMark.vue` و `favicon.svg`) مرسوم SVG بنفس شكل النجوم الثلاث والقوس على جدارهم.
لا يوجد حساب سوشيال ميديا ظاهر للاستوديو، وموقعهم الحالي studiothreestar.com يعرض صفحة الاستضافة الافتراضية (Plesk) مع خطأ شهادة SSL.

## المحتوى
- الخدمة الأساسية من المراجعات: صور الجواز والتأشيرات خلال دقائق + نسخة رقمية على واتساب.
- المقاسات المعروضة (4×6، 5×5، 3.5×4.5) مقاسات شائعة — تأكد منها مع الاستوديو.
- أوقات الدوام والعنوان والهاتف من خرائط Google.
- المراجعات مقتطفات حقيقية من Google.

## أين أعدّل؟
`src/site.js` (واتساب، الهاتف، الخريطة) · `src/i18n.js` (النصوص) · `src/styles.css` (الألوان والخطوط).

## قبل الإطلاق الرسمي
احذف `noindex` من `index.html` وشريط "نسخة عرض" من `src/App.vue`، وأضف أسعار الجلسات وصوراً حقيقية من أعمالهم.
